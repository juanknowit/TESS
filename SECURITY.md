# Security and privacy

## Reporting a vulnerability

Please report security issues privately through [GitHub's private vulnerability reporting](https://github.com/juanknowit/TESS/security/advisories/new) rather than in a public issue. You'll get a reply as soon as possible.

## How TESS handles your data

| What | Where it goes |
|---|---|
| Your voice | Transcribed on your Mac by Apple's on-device speech recognition. Audio is never uploaded. |
| The text of your requests | Sent to the AI provider you choose (Anthropic or OpenAI). With Ollama it never leaves your Mac. |
| Tool results (weather, calendar entries, document text, screenshots) | Sent to your AI provider only when a request needs them. Screenshots are dropped from the conversation after one answer. |
| API keys | Stored in your macOS login keychain, never in files or in this repository. |
| Long-term memories and usage statistics | Stored locally in `~/Library/Application Support/TESS`. Memories are included in requests to your AI provider so it can use them. |
| Spoken replies | Generated by macOS, or sent to OpenAI if you choose the OpenAI voice. |

## Safeguards

- **Messages** can only be sent after TESS has read the draft back and you have replied. This is enforced in code, not just in the AI's instructions.
- **Typing for you** never presses Return or sends anything.
- TESS asks before destructive actions and doesn't store passwords in memory.

## Permissions

TESS asks for microphone, speech recognition, screen recording, files and folders, contacts, calendars, reminders, accessibility and automation access, each only for the skills that need it. You can review and change them in Settings › Permissions, or in System Settings › Privacy & Security.
